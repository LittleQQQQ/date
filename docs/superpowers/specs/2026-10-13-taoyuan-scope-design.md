# 範圍先縮小到桃園：設計規格

日期：2026-10-13

## 目標

可選範圍先縮小到桃園市：
- 約會商圈只有桃園區、青埔、中壢、八德四個有大電影院的商圈。
- 出發站也只能選桃園市內的站。

其他縣市已經建好的資料都不刪：資料檔照樣匯入、資料庫裡的影城、場次、餐廳原封不動。之後要恢復全台，只要改一個設定。

## 已確定的決定

| 項目 | 決定 |
|---|---|
| 商圈 | 桃園市/桃園區、桃園市/青埔（原有）、桃園市/中壢、桃園市/八德 |
| 出發站 | 只能從桃園出發：桃園車站、中壢車站、高鐵桃園站、八德（介壽大智路口） |
| 影城 | 桃園統領威秀、桃園站前 in89 豪華影城、桃園桃知道威秀影城、桃園新光影城、威尼斯影城、星橋國際影城、國賓桃園八德；中壢光影電影館（小型藝術電影館）不納入 |
| 縮小範圍的方式 | 新增設定 `ACTIVE_CITIES`（預設 `桃園市`）；網頁、API、MCP 一致只開放這些縣市；爬蟲只抓這些縣市 |
| 其他縣市的資料 | 不刪除、不再更新 |
| 交通 | 手寫估計值，和其他縣市一樣；這次不加機場捷運、桃園捷運綠線 |

## 開放範圍設定 `ACTIVE_CITIES`

**設定**
- `.env` 的 `ACTIVE_CITIES`：可以填好幾個縣市，用逗號分開，例如 `桃園市` 或 `桃園市,台北市`。
- 預設 `桃園市`；留空代表全台開放（目前的行為）。
- 縣市名稱要能在 `app/regions.py` 的縣市清單找到，打錯時啟動就報錯。

**範圍以外的縣市**

| 地方 | 行為 |
|---|---|
| 網頁選單、`/api/meta`、MCP `list_areas`（`services.list_cities`） | 只列開放縣市，連「尚無資料」也不列；出發站只列開放縣市的 |
| 排程（`/api/plan`、MCP `plan_date`）、查路線（MCP `check_route`） | 商圈或出發站不在開放縣市時，回錯誤「目前只開放桃園市」（多個縣市時用「、」串起來） |
| 查場次（`/api/showtimes`、MCP `search_showtimes`） | 商圈不在開放縣市時，回同樣的錯誤 |
| 查餐廳（`/api/restaurants`、MCP `find_restaurants`） | 影城所在的商圈不在開放縣市時，回同樣的錯誤 |
| 聊天輸入（`/api/chat`） | 本來就從選單資料比對商圈和出發站，所以自然只認得開放縣市的 |

**爬蟲與資料更新**
- 需要商圈涵蓋範圍的爬蟲（開眼、OSM）只拿到開放縣市的商圈。
  - `get_collector` 建立時，`load_coverage` 只載入開放縣市。
  - 開眼只抓桃園的地區頁；OSM 只查桃園四個商圈。
- 其他縣市的資料留在資料庫：
  - 開眼只替換這次抓到的影城的場次，OSM 只替換這次查到的商圈的餐廳。所以其他縣市的資料不會被刪，只是不再更新。
- 商圈與交通（base）照樣匯入 `data/fixture/` 的全部資料檔，所以自動清理不會刪到任何東西。
- 背景更新的時機不變（啟動時補抓、每天定時更新），只是範圍變小。
- **恢復全台：** `ACTIVE_CITIES` 留空後重新啟動。開眼的場次每天會更新，會自動補回來；OSM 要等 7 天的更新週期到了才會重抓，急的話手動執行 `python -m app.ingest --source osm`。

**這次做完後**
- 在 `dev.db` 依序匯入：商圈與交通（base）→ 開眼 → OSM，讓新商圈有影城、場次、餐廳。
- README 的「升級後補抓資料」補上這個步驟。

## 測試

**範圍設定**
- 測試環境的 `ACTIVE_CITIES` 設成空字串（全台），所以現有測試照舊。範圍限制的測試用 monkeypatch 把設定改成 `桃園市`。
- 範圍設成桃園市時：
  - 選單只有桃園的四個商圈、四個出發站。
  - 排信義會回「目前只開放桃園市」。
  - 從台北車站出發排中壢，也會回同樣的錯誤。
  - 查信義的場次、查信義影城附近的餐廳，也會回同樣的錯誤。
  - 爬蟲拿到的涵蓋範圍只有桃園市。
- 設定裡有打錯的縣市名稱時會報錯。

**桃園路網**（`tests/test_taiwan_network.py`）
- `CINEMAS` 表加上七家影城和中壢光影（預期不涵蓋）。
- 四個出發站到四個商圈都去得了、也回得來（考慮首末班車，下午出發、晚上回得去）。
- 現有測試跟著改：
  - 商圈總數 20 → 23（縣市數仍是 19）。
  - 本島商圈清單加上桃園區、中壢、八德。

## 不做的事

- 機場捷運、桃園捷運綠線。
- 中壢光影電影館。
- 刪除其他縣市的資料檔或資料庫資料。
- 恢復全台時自動重抓 OSM（照現有的 7 天週期，或手動執行）。
